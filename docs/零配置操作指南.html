安全更新中心

安裝一次，之後自動判斷。

AutoPatch Hub 會檢查管理器、修補套件、YouTube 相容來源與 MicroG-RE， 自動選擇符合手機 Android SDK 與 CPU 的版本，下載後逐層驗證。

第一次只做三件事

01

安裝

從本專案 GitHub Release 安裝 AutoPatch-Hub-*.apk。

02

允許通知

收到更新時會直接帶你到正確元件，不需要自己找版本。

03

選擇權限

一般模式使用系統確認；想要靜默安裝才授權 Shizuku 或 Root。

每次更新會自動完成

簽章清單SDK／ABI 選版背景下載 SHA-256APK 身分簽署鏈安裝或本機修補

YouTube 為什麼不同？

本專案不散布 Google 原始或預先修補的 YouTube APK。App 只會檢查手機中已安裝 或已保存的合法來源，確認修補套件精確支援後才在手機內合併 split、修補及簽署。 不相容時會等待，不會硬套版本。

Android 必要限制：未授權的普通 App 不能無提示安裝。 所以一般手機仍會看到一次系統安裝確認；已授權 Shizuku／Root 才能完全靜默。

查看狀態

開啟「設定 → 進階 → 安全更新中心」，即可一次看到 AutoPatch Hub、YouTube 本機修補、修補套件與 MicroG-RE。預設全生態自動更新已開啟。
